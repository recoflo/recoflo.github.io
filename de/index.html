So funktioniert es

Drei Schritte, und keiner davon ist Tippen

  1. Drucken

    Ein Deckblatt mit QR-Code für jedes Dokument.

  2. Scannen

    Den ganzen Stapel in einem Durchgang, auf dem Scanner, den Sie schon haben.

  3. Finden

    Jedes Dokument liegt mit seinen Daten im Archiv und lässt sich suchen.

Das Deckblatt

Ein Blatt, zwei Aufgaben

Alles, was Recoflo über ein Dokument wissen muss, steht auf dem Blatt, das obenauf liegt.

Es trennt

Wo ein Deckblatt liegt, beginnt ein neues Dokument. Kein Sortieren von Hand, keine leeren Seiten dazwischen, kein eigener Stapel für jedes Dokument.

Es verknüpft die Daten

Der Code sagt, zu welchem Datensatz die Seiten gehören. Das Dokument kommt mit seinen Daten bereits ausgefüllt an, und niemand tippt sie ein zweites Mal.

Tragen Ihre Dokumente schon einen Code? Dann brauchen sie kein Deckblatt. Und wenn noch keiner da ist, richten wir die Deckblätter mit Ihnen ein: wie sie aussehen und wo sie gedruckt werden.

Wenn ein Code fehlt

Ein Mensch schaut einmal hin, wo es nötig ist

Eine Seite ohne lesbaren Code wird markiert. Sie steht neben ihren Feldern; was fehlt, wird einmal eingegeben, und das Dokument geht weiter.

Das Archiv

Suchen nach dem, was Sie wissen

Eine Rechnungsnummer, eine Kundennummer, ein Datum. Das Ergebnis öffnet sich als Originalseiten und lässt sich als PDF speichern.

White Label

Es trägt Ihren Namen

Recoflo bleibt im Hintergrund. Was Ihre Leute öffnen, ist Ihre eigene Lösung.

Ihr Logo und Ihr Name

Auf jedem Bildschirm, anstelle von unserem.

Ihre Webadresse

Erreichbar unter einer eigenen Adresse.

Deutsch und Englisch

Jeder Bildschirm in beiden Sprachen. Jede Person wählt selbst.

Ihre Felder und Regeln

Was erfasst wird und was als gültig zählt, wird für Sie eingerichtet.
