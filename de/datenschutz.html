Was diese Website nicht tut

Sie setzt keine Cookies. Sie verwendet keine Analyse und kein Tracking. Sie lädt keine Schriften, Skripte oder Bilder von anderen Anbietern, und sie hat keine Formulare.

Was geschieht, wenn Sie eine Seite öffnen

Die Website wird von GitHub Pages ausgeliefert, einem Dienst der GitHub, Inc. in den USA. Um eine Seite auszuliefern, verarbeitet GitHub technische Daten, die Ihr Browser mit jeder Anfrage sendet, darunter Ihre IP-Adresse, und kann sie in seinen Protokollen aufbewahren. Wir haben keinen Zugriff auf diese Protokolle.
