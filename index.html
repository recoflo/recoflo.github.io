How it works

Three steps, and none of them is typing

  1. Print

    A cover sheet with a QR code for each document.

  2. Scan

    The whole stack in one go, on the scanner you already have.

  3. Find

    Each document is in the archive, with its data, ready to be searched.

The cover sheet

One sheet, two jobs

Everything Recoflo needs to know about a document is on the sheet that lies on top of it.

It separates

Where a cover sheet lies, a new document begins. No sorting by hand, no blank pages in between, no separate stack for every document.

It links the data

The code says which record the pages belong to. The document arrives with its data already filled in, and nobody types it a second time.

Is there a code on your documents already? Then they need no cover sheet. And if there is none yet, we set up the cover sheets with you: what they look like and where they are printed.

When a code is missing

A person looks once, where it is needed

A page without a readable code is marked. It is shown beside its fields; what is missing is entered once, and the document moves on.

The archive

Search by what you know

An invoice number, a customer number, a date. The result opens as the original pages and can be saved as a PDF.
